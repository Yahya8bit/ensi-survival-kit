## Exercice 1 (4pts : 1 pt × 4)

**1)** Considérons le code suivant :

```cpp
#include <iostream>
#include <string>
using namespace std;
class Robot
{
public:
  Robot() : energie_(100) {};
  int getEnergie() const { return energie_; }
  void setEnergie(int energie) { energie_ = energie; }
  void travailler()
  { energie_ -= 10;
    cout << "Énergie restante : " << energie_ << endl;}
  bool operator==(Robot r) { return (nom == r.nom); }
private:
  int energie_;
  string nom;
};

Robot chercher(Robot*& usine, Robot r, int pos)
{ cout << "Recherche d'un robot" << endl;
  if (usine[pos] == r) return r; }

void recharger(Robot robot)
{ robot.setEnergie(robot.getEnergie() + 20);
  cout << "Énergie après recharge : " << robot.getEnergie() << endl;}

void reparer(Robot robot)
{ cout << "Énergie avant réparation : " << robot.getEnergie() << endl;
  robot.setEnergie(100);
  cout << "Énergie après réparation : " << robot.getEnergie() << endl;}

int main()
{
  Robot r1;
  Robot* usine = new Robot[3];
  chercher(usine, r1, 1);
  r1.travailler();
  recharger(r1);
  recharger(r1);
  reparer(r1);
  return 0;}
```

Combien d'objets de type `Robot` sont créés lors de l'exécution de ce programme ?
- a) Un
- b) Trois
- c) Quatre
- d) Cinq
- e) Huit

**3)** Soit le code suivant :

```cpp
class G {
  int a;
public:
  G(int val) : a(val) {}
  void setA(int val) {
    a = val; }
  int getA() const {
    return a;
  }
};
class H {
  int b;
public:
  H(int val) : b(val) {}
  inline void setB(int val);
  int getB() const {
    return b;
  }
};
inline void H::setB(int val) {
  this->b = val;}

int main() {
  G objG(5);
  H objH(10);
  objG.setA(15);
  const G& refG = objG;
  refG.getA();
  objH.setB(20);
  const H& refH = objH;
  refH.getB();
  return 0;
}
```

Quelle(s) affirmation(s) est (sont) correcte(s) :
- a) La méthode `setA` dans la classe `G` est plus rapide que `setB` dans la classe `H` car cette dernière est inline.
- b) Le programme est correct et les appels de méthode sur des objets const dans `main` sont valides.
- c) La méthode `getA` dans la classe `G` ne peut pas être appelée sur une référence const car elle n'est pas marquée `const`.

## Problème (10 points)

On s'intéresse dans ce problème à une classe `Polynome` représentant des polynômes à une variable et à coefficients entiers ayant la forme suivante :

```
A = a0x^0 + a1x^1 + a2x^2 + ... + aNx^N
```

avec `N≥0` représentant le degré du polynôme et `ai` un entier naturel représentant le coefficient du degré `i` du polynôme.

On déclare cette classe comme suit :

```cpp
class Polynome
{
private:
  int degre ; //degré du polynome
  int* Tab ; //tableau dynamique de coefficients
  /*Par exemple le tableau:{1,2,0,3} représente le polynôme: 1x^0+2x^1+0x^2+3x^3 */
public:
  Polynome(int d);
  /*permet de créer un polynôme de degré d à coefficients nuls */

  Polynome(int* A, int d);
  /*permet de créer un polynôme de degré d dont les coefficients sont initialisés
  par les éléments du tableau A*/

  void set_coef(int d, int coef);
  /*permet de remplacer par coef le coefficient de degré d s'il existe */
  …} ;
```
