# Devoir surveillé — Novembre 2017

*ENSI — Module : Algorithmique de l'analyse numérique — Classe : I.I.1 — Documents non autorisés — Durée : 2h*

## Exercice N°1 (11 pts = 1.5+1+1+1+1.5+(1.5+1.5+1+1))

Soit `f: ℝ → ℝ` telle que `f ∈ C³([a,b], ℝ)` et soient `a < b` deux réels donnés. On cherche à approcher `f` sur l'intervalle `[a,b]` par un polynôme `p` tel que :

```
(1)   { p(a) = f(a)
      { p(b) = f(b)
      { p'(a) = f'(a)
```

1. Construire les polynômes `h₁, h₂` et `h₃` de degré 2 définis par :
   ```
   { h₁(a) = h₁'(a) = 0, h₁(b) = 1
   { h₂(a) = h₂(b) = 0, h₂'(a) = 1
   { h₃(b) = h₃'(a) = 0, h₃(a) = 1
   ```
2. Montrer que `(h₁, h₂, h₃)` forme une base de l'ensemble `ℝ₂[X]` des polynômes de degré inférieur ou égal à 2.
3. Montrer que tout polynôme de `ℝ₂[X]` vérifiant (1) est unique.
4. Montrer que le polynôme d'interpolation vérifiant (1) s'écrit : `p(x) = f(b)h₁(x) + f'(a)h₂(x) + f(a)h₃(x)`.
5. Montrer que l'erreur d'interpolation s'écrit :
   ```
   (2)   f(x) − p(x) = (x−a)²(x−b)/6 · f⁽³⁾(ξ),   a < ξ < b
   ```
   *(Indication : définir pour `x≠a` et `x≠b` la fonction `Φ(t) = f(t) − p(t) − A(x)(t−a)²(t−b)`, `A(x)` est tel que `Φ(x)=0`.)*

<details>
<summary>Correction</summary>

**1.** On cherche `h₁(x) = C(x−a)²`. `h₁(b)=1 ⟹ C(b−a)²=1 ⟹ C=1/(b−a)²`, d'où **`h₁(x) = (x−a)²/(b−a)²`**.

`h₂(x) = C(x−a)(x−b)`, `h₂'(x) = C(x−b)+C(x−a)`, `h₂'(a)=1 ⟹ C(a−b)=1 ⟹ C=1/(a−b)`, d'où **`h₂(x) = (x−a)(x−b)/(a−b)`**.

`h₃(x) = C(x−b)²`, `h₃(a)=1 ⟹ C(a−b)²=1 ⟹ C=1/(a−b)²`, d'où **`h₃(x) = (x−b)²/(a−b)²`**.

**2.** Il suffit de montrer que `(h₁,h₂,h₃)` est libre. Soit `d₁h₁+d₂h₂+d₃h₃=0`. Pour `x=a` : `d₃=0`. Pour `x=b` : `d₁=0`. Alors `d₂h₂(x)=0 ∀x∈[a,b]`, d'où `d₂=0`.

**3.** Supposons qu'il existe `p,q ∈ ℝ₂[X]` vérifiant (1). Alors `(p−q)(a)=0`, `(p−q)(b)=0`, `(p−q)'(a)=0`. Donc `a` est un zéro double et `b` est un zéro. Comme `p−q ∈ ℝ₂[X]`, on a `p−q ≡ 0`, d'où `p=q`.

**4.** `p(x) = f(b)h₁(x) + f'(a)h₂(x) + f(a)h₃(x)` est de degré ≤ 2, et on vérifie : `p(b)=f(b)`, `p(a)=f(a)`, `p'(x) = f(b)h₁'(x)+f'(a)h₂'(x)+f(a)h₃'(x)`, `p'(a) = 0 + f'(a) + 0 = f'(a)`.

**5.** `Φ(t) = f(t)−p(t)−A(x)(t−a)²(t−b) = 0 ⟹ A(x) = (f(x)−p(x))/((x−a)²(x−b))`.

`Φ(a)=0`, `Φ(b)=0`, `Φ(x)=0`. Il existe `ξ₁,ξ₂` tels que `Φ'(ξ₁)=Φ'(ξ₂)=0` (Rolle). De plus `Φ'(t)=f'(t)−p'(t)−A(x)(2(t−a)(t−b)+(t−a)²)`. `Φ'(a)=0` donc `Φ'` s'annule en 3 points.

`⟹ Φ''` s'annule en 2 points au moins `⟹ Φ⁽³⁾` s'annule en au moins 1 point `η ∈ ]a,b[`. `Φ⁽³⁾(t) = f⁽³⁾(t) − 0 − A(x)·6`.

`Φ⁽³⁾(η)=0 ⟺ A(x) = f⁽³⁾(η)/6`, or `A(x) = (f(x)−p(x))/((x−a)²(x−b)) = f⁽³⁾(η)/6`, d'où le résultat : `f(x)−p(x) = (x−a)²(x−b)/6 · f⁽³⁾(ξ)`.

</details>

## Exercice N°1 (suite) — Formules de quadrature

6.
   - a. Déterminer les réels `α, β` et `γ` pour que la formule de quadrature suivante :
     ```
     (3)   ∫₋₁¹ g(t)dt = αg(−1) + βg'(−1) + γg(1) + E(g)
     ```
     soit exacte sur les polynômes de plus haut degré. Quel est l'ordre de cette formule ?
   - b. Soit `g ∈ C³([a,b], ℝ)`, donner une majoration de l'erreur d'intégration en fonction des dérivées de `g`. *(Indication : utiliser l'égalité (2)).*
   - c. Soit `{xᵢ, i=0,...,M}` une subdivision de `[0,5]` de pas `h`. On cherche à approcher `J(u) = ∫₀⁵ u(x)dx`.
     - (i) Construire, en utilisant (3), une formule d'intégration pour approcher `Jᵢ(u) = ∫_{xᵢ}^{xᵢ+h} u(x)dx`.
     - (ii) Écrire la formule composée correspondante à (3) pour approcher `J(u)`.

<details>
<summary>Correction</summary>

**6.a.** `E(1)=0 ⟹ 2=α+γ` (①). `E(x)=0 ⟹ 0=−α+β+γ` (②). `E(x²)=0 ⟹ 2/3=α+2β+γ` (③).

②+③ : `−β+2γ=2/3`. ①+② : `β+2γ=2`. On résout : `γ=2/3, β=2/3, α=4/3`.

Vérification à l'ordre 3 : `E(x³)=0+4/3−2/3+2/3≠0 ⟹ N=2`.

**Formule (3) :** `∫₋₁¹ g(t)dt = (4/3)g(−1) + (2/3)g'(−1) + (2/3)g(1) + E(g)`.

**6.b.** Soit `p` le polynôme d'interpolation de (1) avec `a=−1, b=1` : `p(−1)=g(−1), p'(−1)=g'(−1), p(1)=g(1)`.

```
E(g) = ∫₋₁¹ g(t)dt − (4/3)g(−1) + (2/3)g'(−1) − (2/3)g(1)
     = ∫₋₁¹ (g(t)−p(t)) dt
     = ∫₋₁¹ (t+1)²(t−1)/6 · g⁽³⁾(ξₜ) dt
```
Par la formule de la moyenne (le signe de `(t+1)²(t−1)` est constant sur `[−1,1]`) :
```
= (1/6)(∫₋₁¹ (t+1)²(t−1) dt) · g⁽³⁾(η) = −(2/9) g⁽³⁾(η)
```

**6.c.(i)** Changement de variable `[xᵢ, xᵢ+h] → [−1,1]`, `t ↦ x = (xᵢ+h−xᵢ)/2 · t + (xᵢ+h+xᵢ)/2` :
```
∫_{xᵢ}^{xᵢ+h} u(x)dx = (xᵢ+h−xᵢ)/2 · [(4/3)u(xᵢ) + (2/3)·(xᵢ+h−xᵢ)/2·u'(xᵢ) + (2/3)u(xᵢ+h)] + Eᵢ(u)
```
soit, en développant :
```
= h/2 · [(4/3)u(xᵢ) + (h/3)u'(xᵢ) + (2/3)u(xᵢ+h)] + Eᵢ(u),   avec |Eᵢ(u)| ≤ h⁴/72 · max_{t∈]xᵢ,xᵢ+h[} |u⁽³⁾(t)|
```

**6.c.(ii)** La formule composée associée :
```
J(u) = ∫₀⁵ u(x)dx = Σᵢ₌₀^{M-1} ∫_{xᵢ}^{xᵢ+h} u(x)dx
     ≈ Σᵢ₌₀^{M-1} h/2 · [(4/3)u(xᵢ) + (h/3)u'(xᵢ) + (2/3)u(xᵢ+h)]
```
avec l'erreur composée `Ecomp(u) = Σᵢ₌₀^{M-1} −h⁴/72 · u⁽³⁾(ηᵢ)`.

</details>

## Exercice N°2 (5 pts = 1.5+1.5+2)

1. Trouver `b` tel que `‖sin x − b‖²_{L²[0,π/2]} = ∫₀^{π/2} |sin x − b|² dx` soit minimal.
2. Trouver le polynôme de degré ≤ 1 qui réalise la meilleure approximation au sens des moindres carrés de `f(x) = x² − x/4 + 1/4` sur `[−1,1]`.
3. Trouver le polynôme de degré ≤ 2 qui réalise la meilleure approximation au sens des moindres carrés discrets associés à `(−1,−3/2), (−1/2,0), (0,1/4), (1/2,0), (1,0)`.

<details>
<summary>Correction</summary>

**1.** `b` est tel que `∫₀^{π/2} (sinx−b)c dx = 0, ∀c∈ℝ`, donc `∫₀^{π/2} b dx = ∫₀^{π/2} sinx dx`, soit `b·π/2 = [−cosx]₀^{π/2} = 1`, d'où **`b = 2/π`**.

**2.** `p(x)=ax+b`. Les conditions d'orthogonalité `∫₋₁¹(f(x)−p(x))dx=0` et `∫₋₁¹(f(x)−p(x))x dx=0` donnent :
```
∫₋₁¹(ax+b)dx = ∫₋₁¹(x²−x/4+1/4)dx  ⟹  2b = 2/3+2/4
∫₋₁¹(ax²+bx)dx = ∫₋₁¹(x³−x²/4+x/4)dx  ⟹  (2/3)a = −2/12
```
On résout : `b = 7/12`, `a = −1/4`. **`p₁(x) = −(1/4)x + 7/12`**.

**3.** On résout l'équation normale `UᵀU·a = Uᵀy` avec :
```
U = [[1,−1,1],[1,−1/2,1/4],[1,0,0],[1,1/2,1/4],[1,1,1]]     y = [−3/2, 0, 1/4, 0, 0]ᵀ
```
```
UᵀU = [[5,0,5/2],[0,5/2,0],[5/2,0,17/8]]      Uᵀy = [5/4, 3/2, −3/2]ᵀ
```
Le système donne `a₂=0` (par la 2ᵉ équation), puis en résolvant `5a₁+5/2·a₃=5/4` et `5/2a₁+17/8·a₃=−3/2` : `a₃=−17/7`, `a₁=−135/28` *(à vérifier — voir la version manuscrite pour le calcul détaillé)*.

</details>

## Exercice N°3 (5 pts = (1+1+1)+1+1)

On considère la formule de quadrature :

```
∫₋₁¹ f(x)/√(1−x²) dx ≈ αf(x₀) + βf(x₁)
```

1. Comment choisir `x₀, x₁, α` et `β` pour que l'ordre de cette formule soit maximal ? Comment appelle-t-on ce type de formule ?
2. Donner une majoration de l'erreur d'intégration.
3. Donner une approximation de `∫₋₁¹ arccos(x)/√(1−x²) dx`.

<details>
<summary>Correction</summary>

**1.** `x₀` et `x₁` sont les zéros du polynôme de Tchebychev `T₂` : `x₀ = cos(π/4) = √2/2`, `x₁ = cos(3π/4) = −√2/2`. `α = ∫₋₁¹ l₀(x) dx/√(1−x²)`, `β = ∫₋₁¹ l₁(x) dx/√(1−x²)`. C'est la **formule de Gauss-Tchebychev à 2 points** (d'ordre 3).

Calcul : `l₀(x) = (x+√2/2)/√2 = (√2/2)x + 1/2 = (√2/2)T₁(x) + (1/2)T₀(x)`, de même `l₁(x) = −(√2/2)T₁(x)+(1/2)T₀(x)`. On trouve `α = π/2`, de même `β = π/2`.

**La formule est :**
```
∫₋₁¹ f(x)/√(1−x²) dx ≈ (π/2)f(√2/2) + (π/2)f(−√2/2)
```

**2.** `E(f) = f⁽⁴⁾(ξ)/4! · ∫₋₁¹ T₂²(x)dx/√(1−x²) = π/48 · f⁽⁴⁾(ξ)`, avec `∫₋₁¹ T₂²(x)dx/√(1−x²) = π/2`.

Majoration : `|E(f)| ≤ π/48 · max_{t∈]−1,1[} |f⁽⁴⁾(t)|`.

**3.** `∫₋₁¹ arccos(x)/√(1−x²) dx = (π/2)[arccos(√2/2) + arccos(−√2/2)] = (π/2)(π/4+3π/4) = π²/2`.

</details>
