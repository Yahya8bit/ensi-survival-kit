# Contrôle — Algorithmique de l'analyse numérique (2021-2022)

*ENSI — Classe : I.I.1 — Date : 9 Novembre 2021 à 9h — Documents non autorisés — Durée : 2h*

Soient `ε ∈ ]0,1[` et `f` une fonction de classe `C³_{[0,1]}`. On note `α = f(0)` et `β = f(1)`.

1. À l'aide de la méthode de Newton, déterminer `Pε(x)` qui interpole `f` aux points `0, ε, 1`.
2. Montrer que `∀x∈[0,1], lim_{ε→0+} Pε(x) = (β−α−f'(0))x² + f'(0)x + α = P(x)`.
3. Vérifier que le polynôme `P` est l'unique polynôme qui vérifie `P(0)=f(0), P(1)=f(1)` et `P'(0)=f'(0)`.
4. Pour `x∈]0,1[` fixé, on considère la fonction `φ` sur `[0,1]` définie par :
   ```
   φ(t) = f(t) − P(t) − (f(x)−P(x))/(x²(x−1)) · t²(t−1)
   ```
   Vérifier que `φ(0)=φ(1)=φ(x)=0` et `φ'(0)=0`.
5. En déduire qu'il existe `μₓ ∈ ]0,1[` tel que `φ⁽³⁾(μₓ)=0` et que :
   ```
   f(x) − P(x) = f⁽³⁾(μₓ)/6 · x²(x−1)
   ```
6. Montrer qu'il existe `c ∈ ]0,1[` tel que :
   ```
   ∫₀¹ f(x)dx = (2/3)f(0) + (1/3)f(1) + (1/6)f'(0) − f⁽³⁾(c)/72
   ```
7. En considérant la formule de quadrature élémentaire suivante :
   ```
   ∫₀¹ f(x)dx = (2/3)f(0) + (1/3)f(1) + (1/6)f'(0) + E(f)
   ```
   Déterminer l'ordre de cette méthode d'intégration numérique.
8. On pose `h = xᵢ₊₁ − xᵢ`. À l'aide d'un changement de variable affine, en déduire une formule de quadrature élémentaire pour l'intégrale `∫_{xᵢ}^{xᵢ+1} f(x)dx`. Préciser dans ce cas l'expression de l'erreur.
9. En subdivisant l'intervalle `[a,b]` en `n` sous-intervalles `[xᵢ,xᵢ₊₁]` de longueur `h=(b−a)/n` avec `(xᵢ=a+ih)ᵢ₌₀,₁,...,ₙ`, déduire la formule de la méthode composée associée pour le calcul de l'intégrale `∫ₐᵇ f(x)dx`. Préciser dans ce cas l'expression de l'erreur.
10. **Application**
    - (i) En subdivisant l'intervalle `[0,1]` en 3 sous-intervalles de longueur `h=1/3` et à l'aide de la formule composée, estimer la valeur de l'intégrale `∫₀¹ xeˣ dx`.
    - (ii) Sachant que `∫₀¹ xeˣ dx = 1`, donner l'erreur commise et conclure.

<details>
<summary>Correction</summary>

**1°)** Table des différences divisées de Newton (base `1, x, x(x−ε)`) :

| base | `xᵢ` | `f(xᵢ)` |
|---|---|---|
| 1 | 0 | α |
| x | ε | f(ε) |
| x(x−ε) | 1 | β |

avec `(f(ε)−α)/ε` et `(β−f(ε))/(1−ε)`, puis `[(β−f(ε))/(1−ε) − (f(ε)−α)/ε]`.

```
Pε(x) = α + x·(f(ε)−α)/ε + x(x−ε)·[(β−f(ε))/(1−ε) − (f(ε)−α)/ε]
```

Vérification : `Pε(0)=α` ✓, `Pε(ε)=f(ε)` ✓, `Pε(1)=f(1)=β` ✓.

**2°)** On a `lim_{ε→0+} (f(ε)−α)/ε = lim_{ε→0+} (f(ε)−f(0))/(ε−0) = f'(0)`.

```
⟹ lim_{ε→0+} Pε(x) = α + xf'(0) + x²(β−f(0))/(1−0) − f'(0))
                    = α + xf'(0) + x²(β−α−f'(0)) = P(x)
```

**3°)** Soit `q` un autre polynôme qui vérifie `q(0)=f(0)`, `q(1)=f(1)` et `q'(0)=f'(0)`. `(P−q)` admet 3 racines : `0` racine double et `1` racine simple. Or `P−q` est un polynôme de degré 2 s'annulant en 3 points, d'où `P−q=0 ⟹ P=q`.

**4°)** `φ(t) = f(t)−P(t) − (f(x)−P(x))/(x²(x−1)) · t²(t−1)`.

`φ(0)=0` et `φ(1)=0` et `φ(x)=0` (par construction du facteur).

`φ'(t) = f'(t)−P'(t) − (f(x)−P(x))/(x²(x−1)) · (2t(t−1)+t²)`.

`φ'(0) = f'(0)−P'(0) − (f(x)−P(x))/(x²(x−1)) × 0 = 0` (car `f'(0)=P'(0)`).

**5°)** D'après 4°), `φ(0)=φ(1)=φ(x)=0`, donc `φ` admet 3 racines distinctes. D'où `φ'` admet au moins 2 racines, en plus `φ'(0)=0`, alors `φ'` admet 3 racines. Finalement `φ'` admet 3 racines, `φ''` admet 2 racines, `φ⁽³⁾` admet 1 racine. D'après le théorème de Rolle, il existe `μₓ ∈ ]0,1[` tel que `φ⁽³⁾(μₓ)=0`.

```
φ⁽³⁾(t) = f⁽³⁾(t) − P⁽³⁾(t) − (f(x)−P(x))/(x²(x−1)) × 6
```
(`P⁽³⁾=0` car `P` de degré 2)

`φ⁽³⁾(μₓ)=0 ⟺ f(x)−P(x) = x²(x−1)/6 · f⁽³⁾(μₓ)`, d'où le résultat.

**6°)** `∫₀¹ (f(x)−P(x))dx = ∫₀¹ x²(x−1)/6 · f⁽³⁾(μₓ) dx`.

```
∫₀¹ f(x)dx = ∫₀¹ P(x)dx + ∫₀¹ x²(x−1)/6 · f⁽³⁾(μₓ) dx
```

```
∫₀¹ P(x)dx = ∫₀¹ [α + xf'(0) + x²(β−α−f'(0))] dx = f(0) + (1/2)f'(0) + (1/3)f(1) − (1/3)f(0) − (1/3)f'(0)
           = (2/3)f(0) + (1/3)f(1) + (1/6)f'(0)
```

`∫₀¹ x²(x−1)/6 · f⁽³⁾(μₓ)dx = f⁽³⁾(c) ∫₀¹ x²(x−1)/6 dx = −f⁽³⁾(c)/72` (car `x²(x−1)` est de signe constant sur `[0,1]`, formule de la moyenne).

Finalement : `∫₀¹ f(x)dx = (2/3)f(0) + (1/3)f(1) + (1/6)f'(0) − f⁽³⁾(c)/72`.

**7°)** On a `E(f) = −f⁽³⁾(c)/72 ⟹ E(1)=E(x)=E(x²)=0` et `E(x³)≠0 ⟹ l'ordre de la méthode est 2`.

**8°)** `[0,1] → [xᵢ,xᵢ₊₁]`, `u ↦ x = xᵢ + (xᵢ₊₁−xᵢ)u = xᵢ+hu`, `dx = h du`.

```
∫_{xᵢ}^{xᵢ+1} f(x)dx = h∫₀¹ f(hu+xᵢ)du = h[(2/3)g(0)+(1/3)g(1)+(1/6)g'(0) − g⁽³⁾(c)/72]
```
avec `g(u)=f(hu+xᵢ)`, `g'(u)=h f'(hu+xᵢ)`, `g⁽³⁾(u)=h³f⁽³⁾(hu+xᵢ)` :
```
= h[(2/3)f(xᵢ)+(1/3)f(xᵢ₊₁)+(h/6)f'(xᵢ)] − h⁴f⁽³⁾(hc+xᵢ)/72
```
**L'expression de l'erreur** : `E(f) = −h⁴f⁽³⁾(hc+xᵢ)/72`.

**9°)** La formule composée associée :
```
∫ₐᵇ f(x)dx = Σᵢ₌₀^{n-1} ∫_{xᵢ}^{xᵢ+1} f(x)dx
           = Σᵢ₌₀^{n-1} h[(2/3)f(xᵢ)+(1/3)f(xᵢ₊₁)+(h/6)f'(xᵢ)] − Ecomp(f)
```
avec `Ecomp(f) = Σᵢ₌₀^{n-1} h⁴f⁽³⁾(hc+xᵢ)/72`.

**10°) Application.** Subdivision `x₀=0, x₁=1/3, x₂=2/3, x₃=1`, `h=1/3`.

```
∫₀¹ xeˣ dx ≈ Σᵢ₌₀² h[(2/3)f(xᵢ)+(1/3)f(xᵢ₊₁)+(h/6)f'(xᵢ)]
```
où `f(u)=ueᵘ`, `f'(u)=(u+1)eᵘ`, `h=1/3` :
```
∫₀¹ xeˣ dx ≈ (1/9) Σᵢ₌₀² [(2/3)xᵢeˣⁱ + (1/3)xᵢ₊₁eˣⁱ⁺¹ + (1/18)(xᵢ+1)eˣⁱ]
```
soit numériquement : `∫₀¹ xeˣ dx ≈ (1/9)[1/6 + (1/3)e^{1/3} + ((13/3−1)/6)e^{1/3} + ((13√2/3+1)/6)e^{2/3} + e]  ≈ 1.0030224812` *(à vérifier)*.

**Conclusion.** Pour une subdivision en 3 sous-intervalles, on a une erreur de l'ordre de `10⁻³`. Donc si on augmente le nombre de sous-intervalles, on peut réduire énormément l'erreur.

</details>
