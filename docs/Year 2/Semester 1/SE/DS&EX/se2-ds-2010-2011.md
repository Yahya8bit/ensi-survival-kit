## Exercice 3 : Synchronisation par sémaphores (6 points)

Une variante du problème producteur-consommateur est constituée de n producteurs qui calculent et déposent au fur et à mesure la suite de leurs résultats dans un tampon et de p consommateurs `(p<n)` qui prennent la suite des résultats déposés pour les utiliser.

Si l'on considère chaque case comme une ressource critique, le but est de synchroniser les différents processus, de sorte à ne pas écraser de l'information dans une même case, ou ne pas retirer d'une case de l'information inexistante. De plus, on souhaite que les informations produites soient consommées dans le même ordre. Pour ce faire, l'ensemble de cases est géré de façon circulaire.

Proposez une solution utilisant les sémaphores et permettant de synchroniser ces processus de manière à respecter les contraintes de synchronisation et d'offrir un haut degré de concurrence entre les différents producteurs et consommateurs.

<details>
<summary>Correction</summary>

Variables partagées :

```c
int entree = 0; // indice de dépôt (producteurs)
sem mutexE = 1; // protéger l'indice d'entrée
int sortie = 0; // indice de sortie (consommateurs)
sem mutexS = 1; // protéger l'indice de sortie
sem plein = 0;  // nombre d'objets prêts à consommer (0 par défaut/initialement)
sem vide = m;   // tampon à m cases, toutes vides initialement
sem mutex[m] = {1, ..., 1}; // chaque case est une ressource critique
```

Producteur :

```c
do {
    P(vide);
    produire_resultat();
    P(mutexE);
    e = entree;
    entree = (entree + 1) % m;
    V(mutexE);
    P(mutex[e]);
    deposer_resultat();
    V(mutex[e]);
    V(plein);
} while (1);
```

Consommateur :

```c
do {
    P(plein);
    P(mutexS);
    s = sortie;
    sortie = (sortie + 1) % m;
    V(mutexS);
    P(mutex[s]);
    retirer_resultat();
    V(mutex[s]);
    V(vide);
} while (1);
```

## Exercice 4 : Synchronisation par moniteurs (5 points)

Un stade d'athlétisme peut recevoir les athlètes de trois (3) clubs A, B et C qui viennent s'y entraîner. Pour organiser les entraînements, on impose la règle suivante :

A un instant donné, le stade peut recevoir un nombre limité (soit N par club) d'athlètes mais de deux clubs au maximum. Par exemple, 5 athlètes du club B et 3 athlètes du Club C peuvent s'entraîner en même temps (ici N=5), mais si un athlète du club A veut accéder au stade, il doit attendre jusqu'à ce que tous les athlètes aient quitté le stade, soit du club B soit du club C.

On vous demande de mettre en œuvre la synchronisation des trois types de processus, correspondant à des athlètes des clubs A, B et C, et ce en utilisant les moniteurs et en évitant la famine.
